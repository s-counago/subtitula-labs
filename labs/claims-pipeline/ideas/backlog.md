# Ideas para iteraciones posteriores

Todavía no son resultados ni compromisos de integración.

El pase de Luna del 11/09/2026 está completado en [el informe comparativo](../reports/resultados-luna.md). Sus resultados añaden prioridades concretas: detectar bloques con baja cobertura, abstenerse ante sujetos financieros ambiguos, conservar literalmente las citas desde el programa y separar fecha del acto, periodo del dato y año presupuestario. Una nueva ejecución con el mismo conjunto será desarrollo; después hace falta un pleno sin usar para ajustar el flujo.

- Revisar los errores del primer ensayo antes de aumentar la complejidad.
- Evaluar estabilidad entre inferencias nuevas conservando las anteriores.
- Comparar recuperación léxica y embeddings para catálogos de asuntos mayores.
- Resolver paráfrasis entre apariciones y sesiones con identidad persistente de persona.
- Evaluar contradicciones únicamente tras alinear propiedad, periodo, modalidad y condiciones.
- Ampliar a grabaciones difíciles después de una sesión municipal con sonido razonable.
- Incorporar el cotejo documental en una fase separada, tal como pidió el usuario.
- Comparar otros modelos solo cuando vuelva a ser relevante; DeepSeek queda fuera de este ensayo.
