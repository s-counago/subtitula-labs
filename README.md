# Subtitula: laboratorios y contexto

Experimentos de extracción de afirmaciones (`labs/claims-pipeline`) y cotejo documental (`labs/jev-evidence`), con sus scripts, fuentes, resultados y documentación.

Los proyectos de aplicación tienen repositorios independientes:

- Frontend: https://github.com/s-counago/subtitula-gal
- API: https://github.com/s-counago/subtitula-gal-api

Para trabajar con el workspace completo, clona ambos repositorios en esas carpetas dentro de este repositorio. Los worktrees y archivos temporales permanecen locales. Las dependencias y el audio original de los ensayos se reconstruyen siguiendo los README de cada laboratorio. El desarrollo alojado continúa suspendido; consulta AGENTS.md y el runbook de la API antes de modificar infraestructura.
